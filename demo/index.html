PlayJev

code OpenJev how it works

PlayJev is an open 0.8B vision-language model (Qwen3.5-0.8B-Base, fine-tuned) that plays ten browser games from raw pixels. Each move is a single forward pass: the current frame goes in, a probability over the game's moves comes out, and no text is generated. The tiles below replay recorded episodes inside the real games and draw the recorded per-step probabilities beside the picture, with the chosen move in blue and the Jev confidence as a number; the label on each tile says whose recording is playing.

all tiles 1x is the game's own pace: one recorded step per move or per 5 to 6 frames.

How it works

The model never sees a game's name. It sees the frame and the option list, rendered with the frozen OpenJev prompt below, and its answer is the next token after "Answer:". The probability over moves is the softmax over the option letters at that position, one forward pass with no sampling and no generated text. Confidence is (pmax - 1/K) / (1 - 1/K), the Jev formula, so 0 is a uniform guess and 1 is certainty. The move with the highest probability is played; a move that leaves the picture unchanged (a blocked direction in 2048 or Sokoban) is not repeated on the same picture, the next most probable move is played instead.

Each tile is the vendored game running in an iframe with the same shim and hook used in training: a virtual clock, seeded randomness and synthetic key events, so the recorded action sequence reproduces the episode step for step. The page checks the replayed score against the recording at the end of every episode and marks a tile in coral if they differ. With ?server=http://host:port in the address the page sends each frame to a running PlayJev or OpenJev server and plays its answers live.
